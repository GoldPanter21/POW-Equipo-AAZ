## Pasos para la ejecución de un clon limpio:

1. [Entrar al link seleccionando este texto.](https://github.com/gabrielhuav/PolitecnicoOpenWorld)<br>
<img src="docs/PasosClon/Paso1.png" width="400">
2. Seleccionar el botón verde y seleccionar "Open with GithubDesktop":<br>
<img src="docs/PasosClon/Paso2.png" width="400">
3. Aparecerá una pantalla de carga mientras se clona el repositorio, al terminar debería verse algo pareceido a esto:<br>
<img src="docs/PasosClon/Paso3.png" width="400">
4. Para poder acceder al archivo y modificar el proyecto, abrimos Android Studio en la carpeta PolitecnicoOpenWorld dentro del repositopositorio raíz.<br>
<img src="docs/PasosClon/Paso4.png" width="400">
